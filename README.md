# Sensei Sushi — сайт и админка

Статический сайт, работает на GitHub Pages. Сервер не нужен.

```
index.html      витрина: сеты, корзина, заказ в WhatsApp
admin.html      админка: заказы, меню, настройки
js/store.js     где лежат данные (браузер или база)
data/menu.json  меню по умолчанию: сеты, цены, состав, настройки
img/            фото сетов и логотип
```

## Как выложить на GitHub Pages
1. Загрузить все файлы и папки в репозиторий.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Сайт: `https://<логин>.github.io/<репозиторий>/`
4. Админка: тот же адрес + `/admin.html`

## Два режима работы

**Локальный (так работает сразу).** Меню берётся из `data/menu.json`.
Заказы уходят в WhatsApp. Правки в админке сохраняются только в том
браузере, где их сделали. Вход в админку — по коду (по умолчанию `1111`,
меняется в «Настройках»). Это защита от случайных людей, а не настоящая:
админка — обычная страница сайта.

Чтобы правки увидели все, в админке: «Подключение» → «Скачать menu.json»
и положить файл в репозиторий вместо `data/menu.json`.

**Облачный (Supabase, бесплатно).** Заказы попадают в базу и видны
в админке с любого устройства, правки меню сразу у всех, вход по почте
и паролю. Настраивается во вкладке «Подключение»: там же готовый SQL
и пошаговая инструкция. Ключ `anon public` открытый — его можно держать
на сайте, доступ закрывают политики RLS из того же SQL.

## Что можно менять в админке
- **Заказы** — статусы (новый → готовится → в пути → доставлен), звонок
  и WhatsApp клиенту в один клик, сумма за день, звук на новый заказ.
- **Меню** — цена, старая цена, метка на фото, короткие значки, фото,
  весь состав, порядок. Выключатель прячет сет с сайта (стоп-лист).
- **Настройки** — номер WhatsApp, часы работы, способы оплаты, подарок,
  жёлтое объявление наверху сайта, пауза приёма заказов.

## Как добавить фото нового сета
Положить картинку в папку `img` (лучше 4:5, например 480×600) и указать
путь в админке: `img/название.jpg`.

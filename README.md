# Sensei Sushi — сайт

Один файл `index.html` + папка `img`. Сервер не нужен — работает на GitHub Pages.

## Как выложить на GitHub Pages
1. Создай репозиторий (например `sensei-sushi`).
2. Загрузи `index.html`, `README.md` и папку `img` целиком.
3. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://<логин>.github.io/sensei-sushi/`.

## Как поменять цены, состав, номер
Всё в начале скрипта в `index.html` (блок «НАСТРОЙКИ» и «СЕТЫ»):
- `WA` — номер WhatsApp для заказов (сейчас 77756678331).
- `OPEN` / `CLOSE` — часы работы (сейчас 11:00–23:40).
- `SETS` — список сетов: название, цена, метка на фото, состав.
  Новый сет: скопируй любой блок `{id:..., ...}`, поменяй `id`, и положи фото `img/<id>.jpg` (лучше 4:5, например 480×600).

## Как работает заказ
Клиент жмёт «В заказ» → внизу появляется кнопка «Оформить заказ» →
вводит имя, телефон, адрес, время, оплату → открывается WhatsApp с готовым текстом заказа.
Корзина и данные клиента сохраняются в браузере, при повторном заходе не надо вводить заново.

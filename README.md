# Sensei Sushi — сайт и админка

Статический сайт, работает на GitHub Pages. Сервер не нужен.

```
index.html      витрина: разделы меню, корзина, заказ в WhatsApp
admin.html      админка: заказы, меню, акции, настройки
js/store.js     где лежат данные (браузер или база)
data/menu.json  меню по умолчанию: разделы, позиции, акции, настройки
img/            фото сетов и логотип
```

Сайт: `https://<логин>.github.io/<репозиторий>/`, админка: тот же адрес + `/admin.html`.

## Разделы меню
В `data/menu.json` есть разделы: Сеты, Роллы, Пиццы, Суши-бургеры, Крылышки и закуски, Новинки.
Пустой раздел на сайте не показывается. Как только в разделе появляется позиция,
на сайте появляется вкладка. У раздела два вида: «Карточки с фото» (как сеты) и «Список».

## Два режима работы

**Локальный (так работает сразу).** Меню берётся из `data/menu.json`. Заказы уходят
в WhatsApp. Правки в админке сохраняются только в том браузере, где их сделали.
Вход в админку по коду (по умолчанию `1111`, меняется в «Настройках»). Это защита
от случайных людей, а не настоящая: админка — обычная страница сайта.

Чтобы правки увидели все: в админке «Меню» → «Скачать menu.json» и положить файл
в репозиторий вместо `data/menu.json`. Номер версии `rev` в скачанном файле
увеличивается сам, поэтому сайт у всех возьмёт новый файл, а не старую копию из браузера.

**Облачный (Supabase, бесплатно).** Заказы попадают в базу и видны в админке
с любого устройства, правки меню сразу у всех, вход по почте и паролю. Настраивается
во вкладке «Подключение»: там готовый SQL и шаги. Ключ `anon public` открытый,
доступ закрывают политики RLS из того же SQL.

## Что умеет админка
- **Заказы** — статусы, звонок и WhatsApp клиенту, звук и счётчик новых заказов,
  выручка и средний чек за сегодня / 7 / 30 дней, топ позиций, поиск по имени,
  телефону и адресу, выгрузка в CSV (открывается в Excel).
- **Меню** — разделы (добавить, переименовать, скрыть, порядок, вид), позиции
  в любом разделе, поиск, копия позиции, перенос между разделами, фото с телефона,
  цена и старая цена, метка, состав, стоп-лист одним выключателем.
- **Акции** — подарок на первый заказ, промокоды (процент или сумма, от какой суммы
  заказа), жёлтое объявление наверху сайта.
- **Настройки** — номер WhatsApp, часы работы, оплата, пауза приёма заказов,
  цена доставки, бесплатная доставка от суммы, минимальная сумма заказа.

Изменения сохраняются сами, отдельной кнопки «Сохранить» нет.

## Фото
Фото, загруженное с телефона, сжимается и хранится прямо в меню. Это удобно,
но утяжеляет меню: если загруженных фото много, лучше класть картинки в папку `img`
(4:5, например 480×600) и указывать путь `img/название.jpg`.
